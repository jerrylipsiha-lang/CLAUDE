# «Без цензуры» — приложение-диалог с Будько и Позовым 📱

Мобильное приложение-болталка: переписка сразу с двумя персонажами, которые
обсуждают **всё подряд, без купюр**.

- **Иван Будько** 🟢 — сельский хитрован: по-русски и просторечно — чарка, сало, огород, жена Валя.
- **Дмитрий Позов** 🔵 — городской циник-ироник: сухо, по факту, без иллюзий.

Они отвечают на любой вопрос, режут правду-матку, шутят грубовато и подкалывают
друг друга. Это **пародия** — персонажи собирательные и комические, не реальные люди.

> Сделано как PWA (Progressive Web App): открывается в браузере телефона и
> ставится на главный экран как обычное приложение. Работает офлайн.

## Как запустить

Приложение — это статические файлы, без сборки и зависимостей.

**Локально:**
```bash
cd phone-app
python3 -m http.server 8000
# открыть http://localhost:8000 в браузере
```

**На телефоне:** опубликуйте папку `phone-app/` на любом статик-хостинге
(GitHub Pages, Netlify, Vercel…), откройте ссылку в Safari/Chrome и выберите
**«Добавить на главный экран»**. Появится иконка — запускается как приложение,
в полноэкранном режиме и без интернета.

## Два режима

### 1. Офлайн (по умолчанию) — работает сразу, без интернета и без ключей
Встроенный движок (`dialogue.js`) подбирает тему по ключевым словам из **15 тем**
(деньги, власть, работа, жена, выпивка, еда, технологии, здоровье, соседи, жизнь,
любовь, город/село, футбол, погода, молодёжь) и выдаёт характерные реплики обоих
героев. Если тема не распознана — отвечают «обо всём» универсальными репликами.
Можно тыкать чипсы тем сверху или жать **🎲 Подкинь тему**.

### 2. Живой режим (ИИ) — динамический разговор через Claude
В ⚙️ настройках включите **«Живой режим»** и впишите свой ключ Anthropic API.
Тогда ответы генерирует модель **Claude** (по умолчанию `claude-opus-4-8`) прямо
в браузере — диалог каждый раз новый, персонажи реагируют на контекст и друг на друга.

> 🔒 **Про безопасность ключа.** Ключ хранится только в вашем браузере
> (`localStorage`) и отправляется напрямую в `api.anthropic.com` (запрос
> с заголовком `anthropic-dangerous-direct-browser-access`). Заведите
> **отдельный ключ с лимитом расходов** — это ваши токены. Для продакшена
> ключ лучше прятать за своим бэкендом-прокси, а не держать в клиенте.

Модель на выбор: Opus 4.8 (умнее), Sonnet 4.6 (быстрее), Haiku 4.5 (дешевле).

## Структура

```
phone-app/
├── index.html            # оболочка
├── styles.css            # тёплая «кухонная» тема, мобильная вёрстка
├── app.js                # чат, офлайн-движок, вызов Claude API, настройки
├── dialogue.js           # библиотека реплик и подбор темы (15 тем)
├── manifest.webmanifest  # PWA-манифест (установка на телефон)
├── sw.js                 # service worker — офлайн-кэш
├── gen-icons.js          # генератор иконок (Node, без зависимостей)
└── icons/                # PNG-иконки 192/512/maskable/apple-touch
```

## Перегенерировать иконки
```bash
node phone-app/gen-icons.js
```

## Технические детали живого режима
- Эндпоинт: `POST https://api.anthropic.com/v1/messages`.
- Структурированный вывод (`output_config.format`, json_schema) — модель
  возвращает массив реплик `{speaker, text}`, чтобы рисовать их отдельными
  пузырями. При сбое парсинга есть запасной вариант (одна реплика).
- Системный промпт задаёт оба характера и просит 2–4 коротких реплики,
  смелых и прямых, но без настоящей жестокости (без оскорблений по
  национальности/полу/религии, без откровенности и опасных инструкций).
- Контекст последних ходов передаётся модели, чтобы разговор был связным.
